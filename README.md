# ItsTomiTv

Site oficial do streamer ItsTomiTv, com identidade gaming premium, dark mode, Twitch OAuth, stream, jogos, parcerias e redes sociais.

## Tecnologias
- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Como correr
```bash
npm install
npm run dev
```

Aceder a http://localhost:3000

## Estrutura principal
- `app/` — páginas e layout principal
- `components/` — cabeçalho, botões e blocos reutilizáveis
- `data/` — conteúdo centralizado para fácil manutenção
